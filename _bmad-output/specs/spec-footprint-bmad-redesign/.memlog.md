- (direction) 使用者要求分析既有 footprint 專案，並加入 BMAD 設計。
- (capability) CAP-1：參與者可在設定頁快速輸入 2–20 位玩家與對應任務，並產生一局可玩的鬼腳圖。
- (capability) CAP-2：每位玩家依序選擇未佔用起點，觀看路徑動畫並清楚得知終點任務。
- (capability) CAP-3：主持人可新增或清除自訂橫線、重播已完成路徑並開始新局。
- (constraint) 維持 React 19 + Vite 7 的純前端與 GitHub Pages 部署模型，不新增後端或持久化。
- (constraint) 介面以繁體中文、行動裝置優先、鍵盤可操作與 prefers-reduced-motion 為設計底線。
- (assumption) 假設主要情境是聚會中由一台共用裝置主持遊戲；使用者尚未指定品牌或視覺風格。
- (question) 是否需要保存玩家名單、歷史結果或多人跨裝置同步，尚待後續確認；本次不納入。
- (event) 規格一致性檢查通過：三項能力均有可判定成功條件，限制與非目標可約束下游決策。
- (event) 來源保存檢查通過：技術棧、核心互動、brownfield 風險與未決範圍已落入 SPEC.md 或 brownfield.md。
- (event) 規格已完成，可供 UX、架構與建置流程使用。
